# Sistem Analisis Kerawanan Banjir

Sistem berbasis web untuk menganalisis dan memvisualisasikan tingkat kerawanan banjir di Kota Pangkalpinang menggunakan SIG dan metode AHP, dengan fitur perhitungan AHP, visualisasi peta, informasi wilayah, mitigasi, serta pengujian sistem menggunakan metode Black-Box Testing.

## Teknologi
- PHP
- HTML
- CSS
- JavaScript
- MySQL
- ArcGIS/QGIS
- XAMPP/Laragon

## Pengujian Sistem
Pengujian dilakukan menggunakan metode Black-Box Testing dengan pembuatan test case untuk memastikan setiap fitur sistem berjalan sesuai dengan kebutuhan dan hasil yang diharapkan.

## Peran
- Analisis sistem
- Pengujian perangkat lunak
- Pembuatan test case
- Analisis hasil pengujian
- Penyusunan laporan

## Project
Proyek ini merupakan tugas akhir untuk menganalisis tingkat kerawanan banjir di Kota Pangkalpinang sebagai media informasi dan edukasi mengenai risiko banjir.
